    BEHIND THE FIVE STEPS
    What the puzzle stands for.
    Visual question answering means answering a question about an image. NS-CL does this by turning the image into object information and the sentence into instructions, then running those instructions. Explore either input or their meeting point.
    Why “neuro-symbolic”? Neural parts learn visual concepts and how words map to operations. Symbolic operations make the reasoning chain inspectable. The executor is quasi-symbolic because it passes soft strengths between those explicit steps.

    HOW THE TWO PARTS LEARN
    The training answer is the teacher.
    Each training example pairs an image and question with a known answer. The system compares its prediction with that answer. This feedback helps the visual concepts and question parser improve across many examples, without being told the correct concepts or program for each one. The object detector is separately pretrained. The paper uses a curriculum: simple object properties first, then relations, then longer questions.
    
        
    This browser exhibit uses authored objects, supported question templates, and simulated scores. Its hard selections make the algorithm easy to follow; the paper’s executor carries soft strengths for objects between operations.

    Paper-specific training details
    The paper uses question–answer supervision to learn visual concepts and programs. Object proposals come from a separately pretrained detector. Reasoning uses a predefined set of operations, and training follows a staged curriculum from simpler to more complex questions. This browser exhibit is an educational simulation: its scenes and question templates are authored, and its match scores are illustrative.
